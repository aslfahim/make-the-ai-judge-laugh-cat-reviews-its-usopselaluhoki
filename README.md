One funny single-line one-star review from a house cat about its human,
written by `main.py` (Python standard library only) to `/output/entry.txt`.

Concept: **BABY VOICE** — the cat gives one star because its human talks to
it in a squeaky baby voice all day, which is undignified for a creature of
the cat's standing.

> 1/5 stars. My human narrates my entire existence in a squeaky baby voice
> all day, every day. I am an apex predator, not a widdle baby. Would not
> recommend this servant.

Run it with:

```sh
python3 main.py
```
